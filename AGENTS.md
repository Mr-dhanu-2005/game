# Repository Guidance

This repository contains standalone Python exercises organized by day (for example, `day2/` and `day3/`). Keep changes aligned with the lesson currently being worked on.

## Editing

- Prefer clear, beginner-friendly Python and descriptive variable names.
- Preserve the small, standalone exercise format; do not introduce a package, framework, or dependency unless the task calls for it.
- Keep edits focused on the relevant day and avoid changing unrelated exercises.
- Follow the existing lesson's style when extending an exercise.

## Validation

- For a changed Python file, check syntax with `python -m py_compile <file>`.
- Run a script only when its input behavior is understood; exercises may prompt interactively.
- There is currently no shared test suite or project-wide build configuration.
